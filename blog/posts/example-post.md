# Welcome to My Blog

This is an example blog post to demonstrate how markdown files are rendered on the website.

## Features

The blog supports:

- **Markdown formatting** - Write in markdown and it gets converted to HTML
- **Code blocks** - Perfect for technical posts
- **Frontmatter** - Add metadata like title and date

## Code Example

Here's a simple code example:

```javascript
function greet(name) {
  return `Hello, ${name}!`;
}

console.log(greet('World'));
```

## Getting Started

To add a new blog post:

1. Create a new `.md` file in the `blog/posts/` directory
2. Add it to `data/blog-manifest.json` with metadata
3. The post will automatically appear in the blog listing!
