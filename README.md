# Personal Website Template

A Next.js + TypeScript starter for a personal site with:
- landing page with contact info and spotlight project
- resume page with embedded PDF and fallback link
- blog index/detail pages sourced from local Markdown files
- projects page with links, optional embeds, and spotlight highlighting

## Quick Start

```bash
npm install
npm run dev
```

## Content Locations

- Profile/projects config: `lib/config.ts`
- Blog markdown files: `content/blog/*.md`
- Resume PDF file: `public/resume/resume.pdf`

## Testing

```bash
npm test
```
